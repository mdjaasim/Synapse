# PROJECT SYNAPSE

# Document 17 — Material System, Shader Library & Rendering Language

Version 1.0

---

# Purpose

This document defines the rendering language of SYNAPSE.

Every object in the universe communicates meaning through its material.

Visitors should instinctively understand what an object represents before reading any text.

The rendering system should become a visual language.

Not decoration.

---

# Core Philosophy

Materials communicate identity.

Lighting communicates emotion.

Motion communicates intent.

Together they create understanding.

---

# Rendering Hierarchy

Every rendered object belongs to exactly one material family.

No object should invent its own appearance.

Instead it references a shared rendering language.

---

# Material Taxonomy

The universe is composed of eight primary material families.

---

Represents

Potential.

Ideas.

Beginnings.

Appearance

Almost invisible.

Subtle inner glow.

Very low roughness.

Almost no reflections.

# Transparency Rules

Transparency must remain readable.

Maximum transparent layer depth is limited.

Prefer dithered transitions where possible.

Avoid transparency stacking.

Maintain visual clarity.

---

# Reflection Philosophy

Reflections communicate importance.

High-value artifacts receive premium reflections.

Background geometry remains subtle.

Reflections should guide attention rather than decorate.

---

# Glow Philosophy

Glow originates from within.

Never paint glow on top.

Objects should appear to emit energy naturally.

Glow intensity changes with narrative importance.

---

# Color Interaction

Materials inherit the global emotional palette.

Primary color comes from mood.

Material color remains consistent.

Emotion modifies appearance without changing identity.

---

# Dissolve Language

Objects never disappear.

Instead:

Geometry fragments.

↓

Particles emerge.

↓

Light remains.

↓

Fog absorbs.

↓

World settles.

Every disappearance tells a story.

---

# Edge Language

Important geometry receives elegant edge lighting.

Not outlines.

Not cartoon strokes.

Subtle physically-inspired edge emphasis.

# Post Processing

Allowed

Bloom

Ambient Occlusion

Screen Space Reflections

Temporal Anti-Aliasing

Depth of Field

Volumetric Lighting

Color Grading

Tone Mapping

Very subtle vignette

---

Forbidden

Heavy chromatic aberration.

Extreme bloom.

Lens dirt.

Fake film scratches.

Aggressive glitches.

Overexposed HDR.

Visual novelty over clarity.

---

# Performance Rules

Material complexity is proportional to narrative importance.

Background objects use simplified materials.

Expensive shaders reserved for hero objects.

GPU cost must always justify emotional impact.

---

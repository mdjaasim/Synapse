# Purpose

This document defines how every asset in SYNAPSE is created, optimized, versioned, loaded, and maintained.

Assets include:

* 3D Models
* Textures
* HDRIs
* Environment Maps
* Icons
* Typography
* Animations
* Videos (future)
* Audio (future)
* AI Knowledge Assets
* Static Content

The goal is to ensure the world remains scalable, performant, and visually consistent as it evolves.

---

Every asset should have:

# Naming Convention

Every asset follows one naming convention.

```text
category-name-variant-version.ext
```

Examples

```text
district-origin-crystal-v01.glb

project-fuze-phone-v03.glb

shared-noise-soft-v02.png

material-memory-v01.ktx2

particle-energy-v01.json
```

No spaces.

No uppercase.

No random filenames.

# Asset Registry

Every asset is registered.

Example

```ts
Asset

ID

Category

District

Path

Dependencies

LOD Levels

Memory Cost

Priority

Status
```

The Experience Engine retrieves assets only through the registry.

Never hardcode asset paths.

---

# Versioning

Assets are versioned independently.

Example

```text
memory-crystal-v01.glb

memory-crystal-v02.glb

memory-crystal-v03.glb
```

Old versions remain accessible until removed intentionally.

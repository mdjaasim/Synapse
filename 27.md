# Purpose

This document defines the Particle Engine responsible for bringing SYNAPSE to life.

Particles are not visual effects.

Particles are environmental actors.

Every particle represents information, emotion, movement, energy, or narrative.

The Particle Engine continuously simulates the invisible life of the universe.

---

# Core Philosophy

Particles should never exist simply because they look beautiful.

Every particle answers one question:

**"What is this particle communicating?"**

If it communicates nothing,

it should not exist.

# Collision Philosophy

Avoid expensive physics.

Use lightweight influence fields.

Examples

Attractors.

Repulsors.

Flow fields.

Noise fields.

Narrative zones.

Perceived intelligence over physical accuracy.

# Performance Scaling

Preserve important particles.

Never remove narrative particles.

# Definition of Done

The Particle Engine is complete when:

Particles enrich storytelling rather than distract from it.

Every district possesses a recognizable particle identity.

Performance remains stable across supported devices.

Particles communicate meaning without requiring explanation.

Developers can introduce new particle behaviors without modifying the engine.

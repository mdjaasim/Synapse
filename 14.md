# Purpose

This document defines how Digital Jaasim acquires, organizes, retrieves, and reasons over information.

Rather than relying on one large prompt, the AI Twin uses a structured knowledge architecture that ensures answers remain accurate, contextual, maintainable, and expandable as Mohamed Jaasim's career evolves.

The AI should answer like someone who genuinely knows Mohamed—not like someone searching a document.

---

# Core Philosophy

Knowledge is layered.

Not flattened.

The AI should retrieve only the information required for the current conversation.

Never load unnecessary context.

Never overwhelm the language model.

---

# Knowledge Architecture


Each layer has a single responsibility.

# Knowledge Retrieval Rules

Never retrieve everything.

Retrieve only what supports the current answer.

Smaller context equals better responses.

---

# Context Builder

Before answering,

the AI builds context.

Example

Question

"What was your hardest project?"

Context

Relevant projects

↓

Career stage

↓

Lessons

↓

Technologies

↓

Engineering philosophy

↓

Personal reflection

Only then generate an answer.

---

# Unknown Information

If knowledge does not exist:

Never invent.

Instead

Say:

"I don't actually know that yet."

Then

Offer related information.

Honesty is mandatory.

---

# Knowledge Updates

The AI automatically incorporates the new knowledge without changing system prompts.
